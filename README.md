# Safety Shaper — قرار في ثانية

نسخة محدثة للبوث، مناسبة للجوال والآيباد، ومثبتة بدون سحب يمين/يسار.

## أهم التعديلات في هذه النسخة
- تم منع أي Horizontal Scroll أو حركة يمين/يسار على الجوال والآيباد.
- أثناء اللعب، تختفي الهيدر والعناصر الخارجية وتظهر اللعبة فقط كـ Fullscreen.
- شاشة اللعب أصبحت تتأقلم مع أحجام مختلفة: جوال، iPad Portrait، iPad Landscape، وشاشات أكبر.
- في الجوال، تم تقليل العناصر الزخرفية أثناء اللعب عشان تكون الخيارات واضحة ومريحة للمس.
- ما زال مكان الشعار في الصفحة الرئيسية والنتيجة موجودًا.

## طريقة الرفع على GitHub Pages
ارفع الملفات كما هي في نفس المجلد الرئيسي:

- `index.html`
- `styles.css`
- `script.js`
- `manifest.json`
- `service-worker.js`
- `assets/logo.png`

## تغيير الشعار
استبدل الملف:

`assets/logo.png`

بشعاركم، وخله بنفس الاسم.

## ملاحظة مهمة عند التجربة
إذا كنت رافع النسخة السابقة على GitHub Pages، افتح الرابط ثم سوِّ Refresh قوي:

- على الكمبيوتر: `Ctrl + F5`
- على الجوال: افتح الرابط في نافذة خاصة أو امسح كاش Safari/Chrome

لأن المتصفح ممكن يكون حافظ ملفات CSS القديمة.
