# Safety Shaper — v5

التعديلات الرئيسية:
- مشهد اللعبة تم تغييره إلى مشهد 3D/Isometric أوضح، مع إبراز الخطر في منتصف المشهد.
- وقت الإجابة 8 ثواني.
- المؤقت داخل المشهد.
- الأجوبة في صف واحد.
- صفحة النتائج أصبحت قابلة للتمرير بدون سحب يمين/يسار.
- `preview.html` محدث للتجربة من اللابتوب مع زر مسح الكاش.

## تشغيل محلي
افتح `preview.html` للتجربة السريعة من اللابتوب.

أو شغل:
```bash
python -m http.server 8000
```

ثم افتح:
```text
http://localhost:8000/preview.html
```

## على GitHub Pages
بعد الرفع، افتح الرابط في نافذة خاصة أو استخدم زر **مسح الكاش** داخل `preview.html`.
