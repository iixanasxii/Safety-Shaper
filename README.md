# Safety Shaper — Fullscreen Booth Mode

تم تعديل النسخة لتعمل كـ Fullscreen Game Mode على الجوال والآيباد.

## أهم التعديلات
- وقت الإجابة أصبح 5 ثواني.
- المؤقت داخل مشهد/فيديو اللعبة.
- إخفاء لوحة النقاط أثناء اللعب لتوفير مساحة.
- الإجابات في صف واحد صغير أسفل الشاشة.
- منع السحب الأفقي يمين/يسار.
- شاشة اللعب تأخذ كامل الشاشة حسب حجم الجهاز.

بعد رفع الملفات، افتح الرابط في نافذة خاصة أو اعمل Hard Refresh لأن Service Worker قد يحفظ النسخة القديمة.
